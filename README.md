RattoLauncher is a W.I.P Modding App for the Nintendo Switch version of the MAD RAT DEAD

Modded files generated with the launcher are compatible with original hardware (in theory, it hasn't been tested yet)

> [Download here](https://github.com/sachikonya808/maddoratto-pc/releases/tag/nightly)

#### Currently supported:
- Custom Textures
- Custom Songs
